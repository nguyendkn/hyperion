## 1. `vllm serve` CLI

- Form: `vllm serve [model_tag] [options]`. Docs list `--model` (default Qwen/Qwen3-0.6B) [V]; the positional `model_tag` form is long-standing [U], not stated on the fetched page. Support both; positional wins over `--model` [U].
- Unknown flags: argparse-style error, exit 2, usage + message [U]. `--help` prints grouped help (config groups; `--help=<group>`/`--help=page` variants) [U]. Bool flags are `--x / --no-x` pairs [V]. JSON args: `--arg '{"k":"v"}'` == `--arg.k v` [V]. Size args accept k/M/G suffixes (`--max-model-len 32k`, `--max-num-batched-tokens`, `--kv-cache-memory-bytes`) [V]. Underscores accepted as hyphens [U].
- `--config file.yaml`: YAML keys = long flag names without `--` (e.g. `port: 8000`, `tensor-parallel-size: 2`); CLI overrides file [V for existence; U for precedence/key form].
- Aliases ARE short flags: `-tp`, `-pp`, `-dp`, `-ep`, `-q`, `-asc`, `-dcp`, `-pcp`, `-n/--nnodes`, `-r/--node-rank` [V].

## 3. HTTP endpoints [U unless stated]
- `GET /health` -> 200 empty body when engine alive; 503 when dead. `GET /ping` (+POST) same as health (SageMaker). `GET /version` -> `{"version":"x.y.z"}`. `GET /metrics` Prometheus text. `GET /v1/models` -> `{"object":"list","data":[{"id":<served name>,"object":"model","created":<int>,"owned_by":"vllm","root":<model path>,"parent":null,"max_model_len":N,"permission":[...]}]}`; with LoRA, adapters listed with `parent`=base. One entry per `--served-model-name` alias.
- `POST /v1/chat/completions`, `POST /v1/completions` (main), `POST /v1/embeddings`, `POST /v1/responses` (+GET/cancel), `POST /v1/messages` (Anthropic) and Cohere-compat exist now [V partially: flags `--anthropic-*`, `--cohere-*` present], `POST /tokenize`, `POST /detokenize`, `POST /pooling`, `POST /score` & `/v1/score`, `POST /rerank` & `/v1/rerank`, `/v1/audio/transcriptions`, `/v1/audio/translations`, `GET /tokenizer_info` (only with `--enable-tokenizer-info-endpoint` [V flag]), `/load` (with `--enable-server-load-tracking` [V flag]), `/v1/load_lora_adapter` & `/v1/unload_lora_adapter` (dev mode), `/sleep` `/wake_up` `/is_sleeping` `/reset_prefix_cache` (dev mode), `/docs` `/openapi.json` (FastAPI; off with --disable-fastapi-docs [V]).
- `/tokenize` body: `{"model","prompt"}` or `{"model","messages",...,"add_generation_prompt":true}`; resp `{"count","max_model_len","tokens":[...],"token_strs":null}`. `/detokenize`: `{"model","tokens"}` -> `{"prompt":"..."}`.
- Chat request fields clients send: model, messages (content str or parts list; roles system/user/assistant/tool/developer), stream, stream_options{include_usage, continuous_usage_stats}, max_tokens, max_completion_tokens, temperature, top_p, n, stop (str|list), seed, presence_penalty, frequency_penalty, logit_bias, logprobs(bool)+top_logprobs(int), response_format{type: text|json_object|json_schema}, tools, tool_choice (none|auto|required|named), parallel_tool_calls, user, `reasoning_effort`. Completions: prompt (str | list[str] | list[int] | list[list[int]]), echo, best_of, suffix, logprobs (int), plus the same.
- vLLM extras (top-level JSON, i.e. what `extra_body` sends): top_k (-1 off), min_p, repetition_penalty, length_penalty, min_tokens, ignore_eos, stop_token_ids, skip_special_tokens (true), spaces_between_special_tokens, include_stop_str_in_output, use_beam_search, truncate_prompt_tokens, prompt_logprobs, add_generation_prompt, continue_final_message, add_special_tokens, chat_template, chat_template_kwargs (e.g. `enable_thinking`), guided_json/guided_regex/guided_choice/guided_grammar/guided_decoding_backend/guided_whitespace_pattern (deprecated) -> `structured_outputs`{json,regex,choice,grammar,json_object,structural_tag,...} (new), `response_format` is the portable path, `priority`, `request_id`, `cache_salt`, `kv_transfer_params`, `return_tokens_as_token_ids`, `return_token_ids`, `vllm_xargs`. Unknown fields: pydantic models allow extras with a warning in recent versions (earlier: ignored) - be lenient, never 400 on unknown keys.
- Defaults: if the model dir has generation_config.json, its temperature/top_p/top_k/repetition_penalty become server defaults (`--generation-config auto` [V]) - affects output parity; max_tokens default = remaining context.
- Non-stream chat response: `{"id":"chatcmpl-<hex>","object":"chat.completion","created":int,"model":<served name>,"choices":[{"index":0,"message":{"role":"assistant","content":"...","reasoning_content"?:..,"tool_calls":[]},"logprobs":null|{"content":[{token,logprob,bytes,top_logprobs[]}]},"finish_reason":"stop|length|tool_calls","stop_reason":null|<matched stop str or token id>}],"usage":{"prompt_tokens","completion_tokens","total_tokens","prompt_tokens_details":null},"prompt_logprobs":null,"service_tier"?,"system_fingerprint"?}`. Completions: id `cmpl-...`, `object:"text_completion"`, choices[].text, logprobs{tokens,token_logprobs,top_logprobs,text_offset}.
- Streaming: `Content-Type: text/event-stream`; each chunk `data: {json}\n\n`, object `chat.completion.chunk`; first chunk delta `{"role":"assistant","content":""}`; then `{"content":"tok"}`; final chunk has finish_reason; if `stream_options.include_usage` an extra chunk with `"choices":[]` and `usage{...}` follows; terminator `data: [DONE]\n\n`. Mid-stream errors are sent as `data: {"error":{...}}`. `--sse-keep-alive-interval` [V] adds keep-alive comments.
- Errors: HTTP status + `{"error":{"message","type":"BadRequestError|NotFoundError|...","param":null,"code":400}}` (older: top-level `object:"error"`, `message`, `type`, `param`, `code`) [U - confirm shape]. Unknown model -> 404 NotFoundError "The model `x` does not exist."; context overflow -> 400 with message containing "maximum context length"; auth fail -> 401 `{"error":"Unauthorized"}`.
- Auth: with `--api-key`/`VLLM_API_KEY`, requests under `/v1/*` need `Authorization: Bearer <key>` (exact match); `/health`, `/metrics`, `/version`, `/ping`, `/docs` are NOT protected [U, widely reported; verify]. Multiple keys supported in recent versions (list) [U].
- served-model-name: request `model` must equal one of the names (or the model path if none set) else 404 unless `VLLM_SKIP_MODEL_NAME_VALIDATION` [V env]; response `model` echoes the requested/served name.

## 4. Prometheus metrics [V unless noted]
All carry label `model_name` (+ `engine`="0" in v1 [U]). Gauges: `vllm:num_requests_running`, `vllm:num_requests_waiting` [named in Grafana section only; type U=gauge], `vllm:kv_cache_usage_perc` (0..1; old `vllm:gpu_cache_usage_perc` is the pre-V1 name [U, page silent]; emit both for old dashboards). Histograms: `vllm:time_to_first_token_seconds`, `vllm:inter_token_latency_seconds`, `vllm:request_time_per_output_token_seconds`, `vllm:e2e_request_latency_seconds`, `vllm:request_queue_time_seconds`, `vllm:request_prefill_time_seconds`, `vllm:request_decode_time_seconds`, `vllm:request_prompt_tokens`, `vllm:request_generation_tokens`, `vllm:request_max_num_generation_tokens`. Info gauge: `vllm:cache_config_info`; `vllm:lora_requests_info`. Removed: `num_requests_swapped`, `cpu_cache_usage_perc`, `avg_prompt_throughput_toks_per_s`. Spec-decode legacy: `vllm:spec_decode_*`. Python process metrics (`python_gc_*`, `process_*`) also appear [U].
Minimum viable set for dashboards/autoscalers/routers (Dynamo, llm-d, KServe, vllm-router): running, waiting, kv_cache_usage_perc, prompt/generation_tokens_total, TTFT, e2e, ITL, request_success_total.
